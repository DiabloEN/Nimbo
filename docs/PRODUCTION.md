# Подготовка к эксплуатации

Это кандидат для проверки, а не обещание готового публичного релиза.

## Отделение от разработки

Используйте отдельный проект Compose, каталог данных, ключи LiveKit и пространство имён сессий. Не переносите `.env`, сертификатные ключи, базы и профили в Git. Шаблоны должны содержать только примеры; установщик генерирует случайные секреты непосредственно на хосте.

На существующем VPS сначала проверьте занятые порты. Второй Caddy не может занять уже используемые TCP 80/443. Для совместного хоста нужна подготовленная маршрутизация через существующий TLS-прокси либо отдельный IP/хост. Самостоятельный установщик не переписывает чужой прокси и откажется при конфликте портов.

## Приёмка

1. Чистый checkout: `npm --prefix web ci --ignore-scripts`, `npm --prefix web test`, `node scripts/build-server.mjs`.
2. Проверка дерева и истории Gitleaks; ручная проверка состава файлов и лицензий. Отсутствие срабатываний сканера не является доказательством отсутствия всех секретов.
3. DNS и новые сертификаты для API, сигналинга и TURN. HTTPS/WSS, правильный Origin, внутренние API-порты недоступны извне.
4. Новый сервер: одноразовый код владельца, его повторное погашение запрещено; приглашение участника, проверки ролей, блокировки, выхода с сервера.
5. Два клиента из разных сетей: голос, переключение микрофона, видео, экран, TURN fallback, переподключение и мини-плеер.
6. Файлы: успешная загрузка, тестовый EICAR, недоступный антивирус, большой архив, отсутствие доступа без сессии, ограничение квоты.
7. Согласованная резервная копия базы и файлов при остановленном API, восстановление в отдельном каталоге, проверка владельца, сообщений и вложений.
8. Зафиксировать контрольные суммы, версию, процедуру отката. Откат бинарника не должен заменять текущие пользовательские данные старой базой.

## Ограничения

Сквозное шифрование сообщений в этой версии отсутствует. Администратор хоста с доступом к базе может прочитать переписку. Нагрузочные испытания и независимый аудит безопасности остаются отдельными этапами подготовки к эксплуатации.
