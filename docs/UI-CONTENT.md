# Согласованные ресурсы интерфейса

## Эффекты камеры

Оригинал: `web/public/effects/room-preview.png`, 1774 × 887, две половины одной фотографии: без эффекта слева, размытый фон справа. Компонент `EffectPicker.vue` использует обе половины как фон карточек. Согласованный вид виден в пользовательских скриншотах настроек камеры.

SHA-256: `71f7b6434bcae4846ee3055ea2c93500db457d3f07eba79a8082f0d66e606cf5`.

При подготовке чистого репозитория `scripts/prepare-source-export.py` намеренно перезаписал оригинал градиентом под тем же именем. 31 октября вместо восстановления была ошибочно добавлена SVG-иллюстрация. Обе замены были самовольными. Исходный ресурс на самом деле сгенерирован для проекта через imagegen; запись об этом есть в локальном `docs/RESUME.md`, исходный prompt — в `artifacts/backlog-qa/effects-preview-prompt.txt`. Основание экспортёра «не включать фотографию реального человека» было ошибочным. Пользователь прямо запретил подобные подмены. Исходная фотография сохранилась в рабочем `web/public/effects/room-preview.png`. Технические тесты предыдущей сборки не доказывали сохранность контента.

`scripts/check-ui-assets.mjs` проверяет оригинал, ссылку компонента и наличие идентичных байтов в готовой сборке. Установочный пакет проходит эту проверку до и после Vite. Изменение эталона допустимо только после согласованной замены ресурса.

В локальном экспортёре удалена генерация градиента; файлы `web/public` копируются без подмены, затем побайтово сравниваются с оригиналами.

Перед релизом дополнительно открыть настройки видео и всплывающие эффекты камеры, сравнить обе карточки с оригиналом на dev и prod. Зафиксировать фактический результат и снимки экрана; не выдавать сборку/тесты за визуальную проверку.
