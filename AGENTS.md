# Правила работы над Nimbo

## Изменения интерфейса

Меняйте изображения, иконки, тексты и поведение только в рамках согласованной задачи. При переносе интерфейса и сборке пакета сохраняйте исходные ресурсы. Если файл пропал, восстановите его из истории версий или резервной копии.

Перед выпуском проверьте ресурсы в готовой сборке и откройте изменённый экран на тестовом сервере. Для эффектов камеры используйте [эталонное изображение и его контрольную сумму](docs/UI-CONTENT.md). В отчёте укажите, какие сценарии проверены автоматически, какие проверены в интерфейсе и какие ещё требуют проверки.

## Обновление сервера

Перед перезапуском API убедитесь, что в голосовых комнатах нет участников. Сохраните резервную копию и проверьте порядок восстановления. При изменениях интерфейса сохраняйте профили, ключи владельца, квоты и пользовательские данные.

См. [проверки перед запуском сервера](docs/PRODUCTION.md). Используйте в документации примеры конфигурации без рабочих паролей и ключей.

## Форматирование кода

Из каталога `web` запустите `npm ci`, затем `npm run format` для форматирования Vue, TypeScript, CSS, HTML и скриптов JavaScript. Команда `npm run format:check` проверяет те же файлы. Для Go используйте `gofmt`. Для Python из корня проекта выполните `ruff format deploy scripts deploy/selfhost/nimbo`.
