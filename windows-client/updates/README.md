# Обновления Nimbo для Windows x64

В 0.3.38 загрузкой управляет приложение, независимо от открытой страницы и выбранного сервера. Под кнопками показываются тонкая полоса, процент и скачанные/полные МБ; при возврате в настройки отображается текущее состояние. Обрыв соединения допускает две автоматические повторные попытки, затем отображается ошибка с возможностью повторить. Пакет проверяется и распаковывается до закрытия клиента. После подтверждения готовности установщика клиент корректно покидает звонок и перезапускается; восстанавливаются сервер, канал и экран, без автоматического включения микрофона. Отдельное окно показывает этап замены файлов и запуска. Модульный путь PowerShell не наследуется от оболочки запуска.

В 0.3.37 установленный клиент обновляет всю папку программы по прежнему пути. После запуска проверяются путь и SHA-256 работающего EXE. Если каталог назначения Portable занят, обновление запускается из новой папки. После успешной установки можно удалить резервную копию, если её содержимое совпадает с описью выпуска. При дополнительных файлах копия сохраняется.

Начиная с 0.3.34 клиент читает `windows-client/updates/windows-x64.json` из ветки `main` репозитория DiabloEN/Nimbo. Для перехода с предварительных версий тот же файл публикуется по прежнему пути `desktop/updates/windows-x64.json`. Проверка выполняется при запуске, раз в шесть часов и по кнопке в общих настройках.

1. Собрать приложение и запустить `scripts/package-native-desktop.py --web web`. Сборщик записывает установщик, Portable ZIP и соответствующий ему `dist/windows-x64.json`.
2. Проверить архив на Windows, запуск распакованной версии и переход с предыдущей поставки с сохранением профиля.
3. Начиная с кандидата 0.3.39, пользовательская распакованная папка и ZIP в корне `dist` содержат `Nimbo.exe`. Для кнопки обновления публиковать в GitHub Releases под тегом `desktop-vX.Y.Z` файл **`dist/updates/Nimbo-Desktop-X.Y.Z-portable.zip`** и использовать **`dist/updates/windows-x64.json`** в обоих публичных путях манифеста. Обновляторы до 0.3.38 включительно проверяют имя `NimboDesktop.exe` внутри ZIP и запускают его под этим именем. Обновлятор из новой сборки распаковывает тот же файл как `Nimbo.exe`. Для обычной установки предназначен `Nimbo-X.Y.Z-Setup.exe`.
4. Сверить размер и SHA-256 опубликованного ZIP с файлом сборщика. Затем опубликовать оба манифеста одним коммитом в `main`. С этого момента новая версия доступна из клиента. Для следующей сборки с другими байтами архива нужен новый номер версии.

Действие «Обновить» доступно для более новой версии. Клиент проверяет размер и SHA-256 скачанного ZIP. Установщик повторно проверяет SHA-256 перед распаковкой. Активный звонок не откладывает установку; завершение проходит через штатный выход из приложения. Для Portable новая версия запускается из соседней папки с тем же каталогом данных. При обычной установке сохраняются путь приложения, файл удаления и предыдущая копия для восстановления.

Для автоматической проверки перехода на временных копиях есть `scripts/test-desktop-update.ps1 -OldPortable <папка предыдущей версии> -Archive <новый ZIP>`. Тест использует одноразовый профиль и имитирует записи реестра установленной копии.

Владелец может одним нажатием поставить серверный выпуск в очередь и запустить установку доступного Windows-выпуска. С 0.3.38 клиентская загрузка не ждёт ответа серверного обновления; его ошибка показывается независимо. Для участника нет запросов к серверному API обновлений. Откат сервера сам по себе не изменяет файлы Windows. После успешной замены EXE установщик запускает новый клиент автоматически.
