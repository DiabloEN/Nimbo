Текстовые каналы, голосовые комнаты и трансляции. Nimbo можно развернуть на собственном VPS и пригласить друзей — управление сервером остаётся у вас.

Проект на GitHub ↗

Своя инфраструктура

Отдельная установка с собственными каналами, ролями и приглашениями.

Профиль с собой

Сохраняйте профиль в защищённом паролем файле .nimbo для переноса между устройствами.

Вход по приглашению

Администратор приглашает участников и определяет доступ к своему серверу.

Готовим первый выпуск. Репозиторий пока приватный — ссылка доступна приглашённым участникам.
